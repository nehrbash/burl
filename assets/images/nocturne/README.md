# Nocturne artwork

`companions.png` is a transparent 1254×1254 painted sprite sheet: four columns
and two rows hold the owl, acorn, plant stages, flower, and empty vessel.

`astral-fragments.png`, `cloud-island.png`, and `astral-glass.png` provide
independently animated scene layers. The four `*-clouds.png` sprite sheets
supply interpolated Blender fog. Dimensions, generation prompts, and rendering
instructions are in `../../atmosphere-source/README.md`.

`crimson-moon.png` includes a painted corona; LunarMoon applies weather phase shading.
