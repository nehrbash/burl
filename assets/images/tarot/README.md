# Tarot workspace portraits

`deck.png` is an original generated 5×2 atlas. Cells have a 2:3 card ratio and a shared antique-gold frame. Reading order: Fool, Magician, High Priestess, Empress, Emperor, Hierophant, Lovers, Chariot, Hermit, Moon.

`TarotCard.qml` crops the atlas at runtime. Workspaces map in order, wrapping after ten cards. The Arabic badge identifies the workspace independently of the card's Roman numeral. Active cards have an ivory frame; empty cards retain their contrast. App icons and monitor markers remain separate.

Generated with the built-in image tool; the complete prompt is in `prompt.txt`.
